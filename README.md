# Map of Knowledge — static site (GitHub Pages)

A fully static, **masked** build of the Map of Knowledge app, for public deployment to GitHub Pages. There is
no backend: every view is pre-built JSON, search runs in the browser, and the AI "Ask" feature is a static
worked-example placeholder. All real client, person, vendor and document names are replaced with
fake-but-realistic placeholders.

The dynamic app (`../backend/` + `../web/`) is unchanged and is still the tool for internal, authenticated use.

## Layout

```
static-sites/
├── export_static.py     # builds the masked JSON from the notes (reuses ../.claude/vault_views.py)
├── mask.py              # deterministic masking + the no-real-token gate
├── compare_parity.py    # structural parity check vs the dynamic app
├── test_mask.py         # masking tests (pytest)
├── src/                 # the React app, copied from ../web and adapted (api.ts -> static loader)
│   ├── api.ts           # fetches public/data/**.json instead of /api/*; search is client-side
│   ├── search.ts        # in-browser search (replaces SQLite FTS5)
│   └── AskPanel.tsx      # static worked-example placeholder (no LLM)
├── public/data/         # GENERATED by export_static.py (gitignored; the deploy workflow rebuilds it)
└── dist/                # GENERATED by vite build (gitignored)
```

## Build and run locally

Prerequisites: Python with PyYAML (`pip install pyyaml`, or use the repo's `.venv`) and Node 20+.

```bash
# from static-sites/
npm install
npm run data        # build the masked JSON  (python export_static.py)
npm run dev         # dev server
# or a production build + local preview:
npm run build       # export_static.py + tsc + vite build  (needs python on PATH)
npm run preview
```

`npm run build:web` runs only `tsc + vite build` (no Python), which is what CI uses after a separate export step.

## Checks

```bash
npm test                                   # frontend component + search tests
python test_mask.py       # or: python -m pytest test_mask.py   (masking + no-leak gate)
python compare_parity.py                   # structural parity vs the dynamic app
```

The masking gate (`mask.py` `verify_clean`, asserted in `export_static.py`) fails the build if any real token
survives in the shipped JSON. This is the only confidentiality control on a public site, so it must pass.

## Deploy to GitHub Pages

`.github/workflows/deploy-static-site.yml` builds and deploys on push to `main` (or manual dispatch). In the
repo: **Settings → Pages → Source: GitHub Actions**.

**Base path:** this is a Project Pages site at `https://<user>.github.io/<repo>/`, so Vite's `base` must be
`/<repo>/`. It is set in **one place** — `BASE_PATH` in the workflow (and the default in `vite.config.ts`). If
the repo is not named `map-of-knowledge`, change `BASE_PATH` to `/<your-repo>/`. For a user/org or
custom-domain site served at the root, use `/`.

To build for a different base locally: `BASE_PATH=/my-repo/ npm run build:web`.
